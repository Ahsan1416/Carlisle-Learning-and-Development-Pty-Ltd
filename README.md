# Carlisle Learning & Workplace Training (RTO 0581)

A high-performance Next.js web application built for **Carlisle Learning & Work Site Training** — an Australian Registered Training Organisation (RTO 0581) based in Mount Barker & Murray Bridge, South Australia.

## Features
- **Authentic Accreditation & Scope:** Full RTO 0581 course directory across Civil & Plant Machinery, High Risk Work (Forklift LF, Boom Lift WP), Construction Safety (White Card, Working at Heights, Confined Spaces), and Austroads Approved Temporary Traffic Management (TC1/TC2, TMI1/TMI2).
- **CITB SA Subsidy Calculator:** Interactive calculator with live out-of-pocket and rebate calculations for eligible South Australian construction workers.
- **Real-Time Search & Filtering:** Dynamic course search by category, unit code, or machinery type.
- **Enterprise Security & Fast SSG Performance:** Fully static pre-rendered routes (36 pages) with JSON-LD Schema markup, dynamic sitemap, robots.txt, and strict HTTP security headers.
- **100% Responsive Design:** Tailored with dark slate (`#0F172A`) and safety amber (`#F59E0B`) styling.

## Getting Started

```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
